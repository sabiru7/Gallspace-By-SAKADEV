# 🤝 Contributing

Kamu juga bisa ikut berkontribusi di GallSpace, baik lewat code maupun hal lainnya.

Beberapa contohnya:

* Bug fixes
* Fitur baru
* UI/UX
* Dokumentasi
* Performa
* Keamanan

### Cara Berkontribusi

```bash
git clone https://github.com/sabiru7/Gallspace-By-SAKADEV
cd Gallspace-By-SAKADEV
```

Buat branch baru:

```bash
git checkout -b feature/nama-fitur
```

Setelah selesai, commit dan push perubahan:

```bash
git add .
git commit -m "feat: add new feature"
git push origin feature/nama-fitur
```

Kemudian buat **Pull Request** ke repository utama.
